# DRY2 Web Components Library - LLM Documentation

## Overview

DRY2 is a comprehensive web components library built with modern web standards, designed for creating interactive and accessible user interfaces. The library leverages Web Components (Custom Elements) with **vanilla JavaScript** for reactivity and state management (no framework dependencies), dry2.css for styling, HTMX for AJAX functionality, and Font Awesome for icons.

**Architecture**: All components extend from a lightweight `BaseElement` base class that provides lifecycle management, event handling, and rendering capabilities **without Shadow DOM**, allowing seamless integration with page styles and third-party libraries.

## Core Dependencies

- **Web Components**: Custom Elements API for component definition
- **Vanilla JavaScript**: Native JavaScript with Proxy-based reactive state management (`VanillaState`)
- **BaseElement**: Custom base class for component lifecycle and rendering
- **dry2.css**: Built-in utility-first CSS framework for styling
- **HTMX**: HTML-over-the-wire for AJAX interactions (optional, used by dialog component)
- **Font Awesome**: Icon library for visual elements (optional, used by button and other components)

## Components Overview

### 1. Accordion Component (`<dry-accordion>`)

Collapsible content sections with smooth animations and keyboard navigation.

**Basic Usage:**
```html
<dry-accordion>
    <accordion-item title="Section 1" open>
        <p>Content for section 1</p>
    </accordion-item>
    <accordion-item title="Section 2">
        <p>Content for section 2</p>
    </accordion-item>
</dry-accordion>
```

**Properties:**
- `multiple` (boolean): Allow multiple sections open simultaneously
- `open` (boolean): Initial open state for accordion-item
- `title` (string): Title text for accordion-item
- `icon` (string): Custom icon HTML for accordion-item

**JavaScript API:**
```javascript
accordion.openAll();     // Open all sections (multiple mode only)
accordion.closeAll();    // Close all sections
accordion.openItem('id'); // Open specific section
accordion.closeItem('id'); // Close specific section
accordion.toggleItem('id'); // Toggle specific section
```

### 2. Avatar Component (`<dry-avatar>`)

User profile images with fallback to initials when images are unavailable.

**Basic Usage:**
```html
<dry-avatar name="John Doe" size="md" shape="circle"></dry-avatar>
<dry-avatar name="Jane Smith" src="https://example.com/avatar.jpg"></dry-avatar>
```

**Properties:**
- `name` (string): User name for auto-generating initials
- `src` (string): Avatar image URL
- `initials` (string): Manually set initials (overrides name)
- `size` (string): 'xs', 'sm', 'md', 'lg', 'xl'
- `shape` (string): 'circle', 'square', 'rounded'

**Custom Content:**
```html
<dry-avatar name="John Doe" size="lg">
    <div class="absolute bottom-0 right-0 w-3 h-3 bg-green-500 rounded-full"></div>
</dry-avatar>
```

### 3. Badge Component (`<dry-badge>`)

Status indicators, counts, or labels with positioning and styling options.

**Basic Usage:**
```html
<dry-badge variant="primary">New</dry-badge>
<dry-badge variant="success">5</dry-badge>
<dry-badge dot variant="danger"></dry-badge>
```

**Properties:**
- `variant` (string): 'primary', 'success', 'danger', 'warning', 'info'
- `size` (string): 'sm', 'md', 'lg'
- `dot` (boolean): Display as dot without content
- `position` (string): 'top-right', 'top-left', 'bottom-right', 'bottom-left'
- `max` (number): Maximum value for numeric badges (shows "99+" format)

**Positioning:**
```html
<div class="relative">
    <button>Notifications</button>
    <dry-badge position="top-right" variant="danger">5</dry-badge>
</div>
```

### 5. Button Component (`<dry-button>`)

Interactive buttons with variants, sizes, icons, and states.

**Basic Usage:**
```html
<dry-button variant="primary" size="md">Click me</dry-button>
<dry-button variant="outline" icon="fas fa-plus">Add Item</dry-button>
<dry-button href="/link" variant="primary">Link Button</dry-button>
```

**Properties:**
- `variant` (string): 'primary', 'secondary', 'outline', 'text', 'danger', 'success', 'warning'
- `size` (string): 'sm', 'md', 'lg', 'xl'
- `icon` (string): Font Awesome icon classes
- `disabled` (boolean): Disable button interaction
- `loading` (boolean): Show loading state
- `href` (string): Render as link instead of button
- `target` (string): Link target attribute

**JavaScript API:**
```javascript
button.setLoading(true);
button.setDisabled(true);
button.setText('New Text');
```

### 8. Code Component (`<dry-code>`)

Syntax-highlighted code blocks with copy-to-clipboard functionality using vanilla JavaScript.

**Basic Usage:**
```html
<dry-code language="javascript">
function greet(name) {
    return `Hello, ${name}!`;
}
</dry-code>
```

**Properties:**
- `language` (string): Programming language for syntax highlighting
- `theme` (string): Color theme for syntax highlighting ('light', 'dark')
- `copy` (boolean): Enable copy-to-clipboard button (default: true)
- `line-numbers` (boolean): Show line numbers

**Features:**
- Built-in syntax highlighting for multiple languages
- One-click copy-to-clipboard functionality
- Responsive design with horizontal scrolling for long lines
- XSS protection for code content

### 9. Countdown Component (`<dry-countdown>`)

Time-based countdown displays with customizable formats using vanilla JavaScript state management.

**Basic Usage:**
```html
<!-- Countdown to specific date -->
<dry-countdown target="2024-12-31T23:59:59"></dry-countdown>

<!-- Countdown with duration -->
<dry-countdown duration="3600"></dry-countdown>
```

**Properties:**
- `target` (string): Target date/time in ISO format
- `duration` (number): Duration in seconds (alternative to target)
- `format` (string): Display format ('dhms', 'hms', 'ms', 's')
- `show-labels` (boolean): Show unit labels (days, hours, etc.)
- `compact` (boolean): Compact display mode

**Events:**
- `countdown:complete`: Fired when countdown reaches zero
- `countdown:tick`: Fired on each second update

**JavaScript API:**
```javascript
const countdown = document.querySelector('dry-countdown');
countdown.start();
countdown.pause();
countdown.reset();
countdown.addEventListener('countdown:complete', () => {
    console.log('Countdown finished!');
});
```

### 10. Dialog Component (`<dry-dialog>`)

Modal dialogs and slide-out drawers with HTMX integration, built with vanilla JavaScript.

**Basic Usage:**
```html
<!-- Modal Dialog -->
<dry-dialog
    url="content.html"
    button-class="bg-blue-500 text-white px-4 py-2 rounded"
    dialog-class="bg-white rounded-lg shadow-xl max-w-lg w-full">
    Open Dialog
</dry-dialog>

<!-- Slide-out Drawer -->
<dry-dialog
    url="drawer-content.html"
    mode="drawer"
    direction="right"
    button-class="bg-blue-500 text-white px-4 py-2 rounded"
    drawer-class="bg-white w-96 h-full">
    Open Drawer
</dry-dialog>
```

**Properties:**
- `url` (string): AJAX content URL (loaded via HTMX)
- `mode` (string): 'dialog' (default) or 'drawer'
- `direction` (string): 'left', 'right', 'top', 'bottom' (drawer only, default: 'right')
- `button-class` (string): CSS classes for trigger button
- `dialog-class` (string): CSS classes for dialog container
- `drawer-class` (string): CSS classes for drawer container (drawer mode only)
- `trigger-id` (string): Custom ID for trigger element
- `dialog-inner-id` (string): Custom ID for content container

**Events:**
- `dialog:open`: Fired when dialog/drawer opens
- `dialog:close`: Fired when dialog/drawer closes
- `dialog:loaded`: Fired when HTMX content finishes loading

**Features:**
- Backdrop click to close (for dialogs)
- ESC key to close
- Focus trap for accessibility
- Smooth slide animations for drawers
- MutationObserver to preserve button text content
- XSS protection for all attributes

**JavaScript API:**
```javascript
const dialog = document.querySelector('dry-dialog');
dialog.open();
dialog.close();
dialog.addEventListener('dialog:open', () => {
    console.log('Dialog opened');
});
```

### 17. Toggle Switch Component (`<toggle-switch>`)

Binary state switches with custom styling and accessibility support using vanilla JavaScript.

**Basic Usage:**
```html
<toggle-switch name="notifications" label="Email Notifications" checked></toggle-switch>
<toggle-switch name="darkmode" size="lg" active-bg="bg-purple-500"></toggle-switch>
```

**Properties:**
- `name` (string): Form field name
- `label` (string): Toggle label text
- `checked` (boolean): Initial checked state
- `disabled` (boolean): Disable toggle interaction
- `size` (string): 'sm', 'md', 'lg'
- `active-bg` (string): CSS classes for active background
- `inactive-bg` (string): CSS classes for inactive background
- `switch-color` (string): CSS classes for switch handle

**Events:**
- `toggle:change`: Fired when toggle state changes with `event.detail.checked`

**JavaScript API:**
```javascript
const toggle = document.querySelector('toggle-switch');
toggle.setChecked(true);
toggle.setDisabled(true);
toggle.addEventListener('toggle:change', (e) => {
    console.log('Checked:', e.detail.checked);
});
```

Interactive component builder for creating live component demonstrations with property controls.

    {
        "componentTag": "dry-button",
        "title": "Button Component Builder",
        "description": "Try changing the button properties dynamically.",
        "properties": {
            "variant": {
                "type": "select",
                "label": "Variant",
                "options": [
                    {"value": "primary", "label": "Primary"},
                    {"value": "secondary", "label": "Secondary"},
                    {"value": "outline", "label": "Outline"}

            "size": {
                "type": "select",

                    {"value": "sm", "label": "Small"},
                    {"value": "md", "label": "Medium"},
                    {"value": "lg", "label": "Large"}
                ]
            },

                "type": "checkbox",

            }

            "variant": "primary",

**Properties:**

**Features:**
- Live component preview
- Dynamic property controls
- Generated code display with syntax highlighting
- Copy-to-clipboard functionality
- Support for multiple control types
- XSS protection for all user inputs

## Implementation Patterns

### Basic Setup (CDN/Individual Files)
```html
<!DOCTYPE html>
<html>
<head>
    <!-- dry2.css for styling -->
    <link rel="stylesheet" href="src/dry2/css/dry2.css">
    
    <!-- HTMX for AJAX (optional, only needed for dialog component) -->
    <script src="https://unpkg.com/htmx.org@2.0.4"></script>
    
    <!-- Font Awesome for icons (optional) -->
    <link href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css" rel="stylesheet">
    
    <!-- DRY2 Core (required) -->
    <script src="src/dry2/base.js"></script>
    <script src="src/dry2/vanilla-state.js"></script>
    
    <!-- Load specific components as needed -->
    <script src="src/dry2/button.js"></script>
    <script src="src/dry2/avatar.js"></script>
    <script src="src/dry2/dialog.js"></script>
</head>
<body>
    <!-- Use components -->
    <dry-button variant="primary">Click me</dry-button>
    <dry-avatar name="John Doe"></dry-avatar>
</body>
</html>
```

### Bundled Setup (Recommended for Production)
```html
<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="src/dry2/css/dry2.css">
    <script src="https://unpkg.com/htmx.org@2.0.4"></script>
    <link href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css" rel="stylesheet">
    
    <!-- Single bundled file with all components -->
    <script src="dist/dry2.js"></script>
</head>
<body>
    <!-- All components available -->
</body>
</html>
```

### Component Loading Order
Components depend on the base infrastructure:
```javascript
// 1. Core base class (required first)
<script src="src/dry2/base.js"></script>

// 2. State management system (required for reactive components)
<script src="src/dry2/vanilla-state.js"></script>

// 3. XSS prevention utilities (optional but recommended)
<script src="src/dry2/xss-prevention.js"></script>

// 4. Individual components
<script src="src/dry2/accordion.js"></script>
<script src="src/dry2/avatar.js"></script>
<script src="src/dry2/badge.js"></script>
// ... etc
```

### Styling Guidelines
- Components use dry2.css utility classes for styling

### Event Handling
All components emit custom events using the native CustomEvent API:
```javascript
// Example: Accordion events
const accordion = document.querySelector('dry-accordion');
accordion.addEventListener('accordion:change', (event) => {
    console.log('Section changed:', event.detail);
});

// Example: Toggle switch events
const toggle = document.querySelector('toggle-switch');
toggle.addEventListener('toggle:change', (event) => {
    console.log('Toggle state:', event.detail.checked);
});

// Example: Dialog events
const dialog = document.querySelector('dry-dialog');
dialog.addEventListener('dialog:open', () => {
    console.log('Dialog opened');
});
dialog.addEventListener('dialog:close', () => {
    console.log('Dialog closed');
});

// Example: Countdown events
const countdown = document.querySelector('dry-countdown');
countdown.addEventListener('countdown:complete', () => {
    console.log('Countdown finished!');
});
```

### State Management
Components use VanillaState for reactive state:
```javascript
// Internal component state example (from component implementation)
class MyComponent extends BaseElement {
    constructor() {
        super();
        this._state = new VanillaState({
            isOpen: false,
            count: 0
        });
        this.reactive = this._state.createReactive();
    }
    
    // Watch for state changes
    setupWatchers() {
        this._state.watch('isOpen', (newValue, oldValue) => {
            console.log('isOpen changed:', newValue);
            this.updateView();
        });
    }
}
```

### Accessibility Features
- **Keyboard navigation**: Full keyboard support (Tab, Enter, Escape, Arrow keys)
- **ARIA attributes**: Proper roles, labels, and states for screen readers
- **Focus management**: Logical tab order and focus trapping in modals
- **Semantic HTML**: Uses appropriate HTML5 elements
- **Color contrast**: WCAG AA compliant color combinations
- **Screen reader announcements**: Live regions for dynamic content

## Best Practices

1. **Component Loading**: 
   - Load `base.js` and `vanilla-state.js` first
   - Only load components you actually use
   - Use bundled `dist/dry2.js` for production
   - Consider code splitting for large applications

2. **Styling**: 
   - Use dry2.css utility classes for consistent styling
   - Pass custom classes via component properties
   - Avoid inline styles; use dry2.css classes instead
   - Test responsive breakpoints (sm, md, lg, xl)

3. **Event Handling**: 
   - Use addEventListener for all component events
   - Event names follow pattern: `component:action`
   - Always check `event.detail` for event data
   - Clean up listeners when removing components

4. **Performance**: 
   - Components render asynchronously with setTimeout(0)
   - Use MutationObserver sparingly
   - Leverage event delegation for dynamic content
   - Avoid excessive re-renders by batching state updates

5. **Accessibility**: 
   - Test with screen readers (NVDA, JAWS, VoiceOver)
   - Verify keyboard navigation works without mouse
   - Check color contrast ratios
   - Use semantic HTML elements
   - Provide meaningful ARIA labels

6. **Security**:
   - All components include XSS protection
   - User input is sanitized automatically
   - Avoid using `innerHTML` with untrusted content
   - Use `textContent` for plain text

7. **Form Integration**: 
   - Use `name` attribute for form field components
   - Components work with standard form submission
   - Access form data via `FormData` API
   - Listen for `change` events for validation
