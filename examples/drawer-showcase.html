Component API

Attributes:

  • url - The URL to fetch content from (required)
  • mode - "dialog" (default) or "drawer"
  • direction - "right" (default), "left", "top", or "bottom" (drawer mode only)
  • trigger-id - ID for the trigger button (required)
  • dialog-inner-id - ID for the content container (required)
  • button-class - CSS classes for the trigger button
  • dialog-class - CSS classes for the dialog (dialog mode)
  • drawer-class - CSS classes for the drawer (drawer mode)
  • trigger-type - "click" (default), "mouseenter", "focus", or "load"

JavaScript API

Methods:

  • open() - Open the dialog/drawer
  • close() - Close the dialog/drawer
  • isOpen() - Check if the dialog/drawer is open
  • setContent(content) - Set the content directly

Events:

  • dialog:opened - Fired when dialog/drawer opens
  • dialog:closed - Fired when dialog/drawer closes
  • dialog:error - Fired when an error occurs
