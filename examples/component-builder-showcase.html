Component Builder

Interactive component builder for creating and testing components with live preview and code generation.

Programmatic API

Control the component builder programmatically using JavaScript.

// Update a single property document.querySelector('dry-component-builder').updateProperty('variant', 'danger'); // Get a property value const variant = document.querySelector('dry-component-builder').getProperty('variant'); // Get all properties const allProps = document.querySelector('dry-component-builder').getAllProperties(); console.log(allProps); // Set configuration dynamically const builder = document.querySelector('dry-component-builder'); builder.setConfig({ componentTag: 'dry-button', title: 'Custom Builder', properties: { /* ... */ }, defaults: { /* ... */ } });

Features

Key features of the Component Builder component.

  • Live Preview: See component changes in real-time as you adjust properties
  • Code Generation: Automatically generates clean HTML code for the configured component
  • Multiple Control Types: Supports select, checkbox, range, and text input controls
  • Copy to Clipboard: One-click copy of generated code
  • Programmatic API: Full JavaScript API for dynamic control
  • XSS Protection: Built-in HTML escaping for security
  • No Dependencies: Pure vanilla JavaScript with no framework required

Configuration Structure

Example configuration JSON for creating a component builder.

{ "componentTag": "dry-button", "title": "Button Builder", "description": "Customize button properties and see the results in real-time.", "properties": { "variant": { "type": "select", "label": "Variant", "options": [ { "value": "primary", "label": "Primary" }, { "value": "secondary", "label": "Secondary" } ] }, "size": { "type": "select", "label": "Size", "options": [ { "value": "sm", "label": "Small" }, { "value": "md", "label": "Medium" } ] }, "disabled": { "type": "checkbox", "label": "Disabled" }, "text": { "type": "text", "label": "Button Text" } }, "defaults": { "variant": "primary", "size": "md", "disabled": false, "text": "Click Me" } }
