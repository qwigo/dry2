API Reference

Card Properties

Property Type Default Description
variant string 'filled' Visual style: 'filled', 'outlined', 'elevated'
elevation string 'md' Shadow level: 'none', 'sm', 'md', 'lg', 'xl'
orientation string 'vertical' Layout direction: 'vertical', 'horizontal'
interactive boolean false Whether the card has hover effects and can be clicked
bordered boolean false Whether to show a border

Card Slots

Slot Description
media Images, videos, or other media content
header Card title and subtitle
body Main card content
footer Actions and metadata

Methods

Method Parameters Description
setVariant(variant) string Change the card variant
setElevation(elevation) string Change the card elevation/shadow
setInteractive(interactive) boolean Enable/disable interactive behavior
setBordered(bordered) boolean Show/hide border

Events

Event Detail Description
card:click { element } Fired when an interactive card is clicked
